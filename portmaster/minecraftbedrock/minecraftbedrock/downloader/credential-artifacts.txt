# Every path under the downloader state directory that can hold Google account
# data. This file is the single source of truth: run.sh deletes exactly this
# list on sign-out, and scripts/check_downloader_policy.py verifies that the
# downloader cannot leave account data anywhere else.
#
# Format: <kind> <path relative to the downloader state directory>
#   transient  written while a sign-in is in flight; removed on every run.sh
#              exit as well as on sign-out
#   session    the saved Google Play session; removed on sign-out
#   dir        private per-session directory tree; removed on sign-out
#
# Paths must be relative, must not escape the state directory, and must never
# live in a shared or user-visible location.
